# ☀️ Solar Calculator - by Logenja-solar

A simple Python tool to calculate solar panels, battery size and cost for a home in Kenya.

Built by a Solar Installer in Mombasa learning Python to make solar affordable and easy to understand.

## What it does
- Asks how many watts you use per day
- Calculates how many 550W panels you need
- Calculates battery size needed
- Estimates total cost in KES

## How to run
```bash
python solar_calculator.py
```
## Example
If you use 2000 watts per day in Mombasa:
- Panels needed: 1 x 550W
- Battery: 3000 Wh
- Total Estimate: ~93,000 KES
